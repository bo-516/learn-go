=== struct
name: 结构体 struct
group: 结构体与方法
--- body
结构体把多个字段组合成一个类型。字段名**首字母大写**表示可以被其他包访问（导出），小写只在当前包可见。

**写法**

```go
type User struct {
	ID    int64
	Name  string
	email string     // 小写：包外不可见
	Tags  []string
}

type ListNode struct {
	Val  int
	Next *ListNode   // 自引用必须用指针
}

point := struct{ X, Y int }{1, 2} // 匿名结构体，临时用
```

**例子**

```go
type Stack struct {
	items []int
}

func (s *Stack) Push(v int) { s.items = append(s.items, v) }
func (s *Stack) Len() int   { return len(s.items) }
```

**注意**

- 结构体是**值类型**：赋值、传参都会复制所有字段（切片、map 字段只复制“引用”，底层数据仍共享）。
- 所有字段都可比较时，结构体可以用 `==` 比较，也能做 map 的 key。
- 字段顺序会影响内存对齐和结构体大小，见「unsafe 与内存布局」。
- 空结构体 `struct{}` 大小为 0，常用于集合和信号 channel。

=== struct-literal
name: 结构体字面量
group: 结构体与方法
--- body
结构体字面量用来创建结构体值。推荐写**字段名**，没写到的字段自动是零值；前面加 `&` 直接得到指针。

**写法**

```go
u := User{Name: "Tom", ID: 1}   // 按字段名，顺序无所谓
u := User{1, "Tom", "", nil}    // 按位置，必须写全且按顺序（不推荐）
p := &User{Name: "Tom"}         // 指针
var zero User                   // 全部是零值
nodes := []*TreeNode{{Val: 1}, {Val: 2}} // 切片元素类型可以省略
```

**例子：构造函数**

```go
func NewServer(addr string) *Server {
	return &Server{
		addr:    addr,
		timeout: 5 * time.Second, // 多行写法最后一个字段后面也要有逗号
		conns:   make(map[string]net.Conn),
	}
}
```

**注意**

- 多行字面量**每行末尾都要有逗号**，包括最后一行。
- 按位置初始化在结构体加字段后会编译失败，所以除了很小的类型（如 `Point{1, 2}`），都用字段名。
- Go 没有构造函数语法，惯例是写 `NewXxx` 函数，返回 `*Xxx`。

=== struct-tag
name: 结构体标签 tag
group: 结构体与方法
--- body
字段后面的反引号字符串是**标签**，编译器不管它的含义，运行时由 `encoding/json`、数据库、校验等库通过反射读取，用来控制字段如何被处理。

**写法**

```go
type User struct {
	ID       int64     `json:"id" db:"id"`
	Name     string    `json:"name"`
	Email    string    `json:"email,omitempty"` // 零值时省略
	Password string    `json:"-"`               // 永远不序列化
	Created  time.Time `json:"created_at"`
}
```

**例子：读取标签**

```go
t := reflect.TypeOf(User{})
f, _ := t.FieldByName("Email")
fmt.Println(f.Tag.Get("json")) // email,omitempty
```

**注意**

- 格式是 `key:"value"`，多个键用**空格**分隔，冒号后不能有空格；写错格式不会编译报错，`go vet` 会提示。
- **只有导出字段（首字母大写）**才会被 json 等包处理，小写字段即使写了 tag 也会被忽略。
- `omitempty` 对 `time.Time` 这类结构体不生效（它永远不是“空”），Go 1.24 新增了 `omitzero`。

=== embed
name: 结构体嵌入（组合）
group: 结构体与方法
--- body
在结构体里只写类型、不写字段名，就是**嵌入**。被嵌入类型的字段和方法会被“提升”到外层，可以直接调用。这是 Go 用组合代替继承的方式。

**写法**

```go
type Animal struct{ Name string }

func (a Animal) Hello() string { return "I'm " + a.Name }

type Dog struct {
	Animal          // 嵌入
	Breed string
}

d := Dog{Animal: Animal{Name: "Rex"}, Breed: "husky"}
d.Hello()          // 直接调用 Animal 的方法
d.Name             // 直接访问 Animal 的字段
d.Animal.Name      // 也可以写全
```

**例子：嵌入锁**

```go
type Counter struct {
	sync.Mutex
	n int
}

func (c *Counter) Inc() {
	c.Lock()          // 提升的方法
	defer c.Unlock()
	c.n++
}
```

**注意**

- 嵌入不是继承：`Dog` 不能赋值给 `Animal` 类型的变量，被嵌入类型的方法里 `a` 仍然是 `Animal`，没有“多态重写”。
- 嵌入导出的 `sync.Mutex` 会把 `Lock/Unlock` 也暴露给包外调用方，库代码里更推荐写成具名字段 `mu sync.Mutex`。
- 嵌入接口可以组合接口：`type ReadWriter interface { Reader; Writer }`。
- 外层定义了同名字段 / 方法时，外层的优先（遮蔽）。

=== method-ptr
name: 方法与接收者
group: 结构体与方法
--- body
方法就是带**接收者**的函数。接收者可以是值 `(c Counter)` 或指针 `(c *Counter)`：需要**修改**接收者、或者结构体较大、或者包含锁时，用指针接收者。

**写法**

```go
type Counter struct{ n int }

func (c *Counter) Inc()     { c.n++ }      // 指针接收者：能修改
func (c Counter) Value() int { return c.n } // 值接收者：拿到的是副本

var c Counter
c.Inc()   // Go 自动转成 (&c).Inc()
p := &c
p.Value() // 自动转成 (*p).Value()
```

**例子：链表实现的栈**

```go
type node struct {
	val  int
	next *node
}

type Stack struct {
	top  *node
	size int
}

func (s *Stack) Push(v int) {
	s.top = &node{v, s.top}
	s.size++
}

func (s *Stack) Pop() (int, bool) {
	if s.top == nil {
		return 0, false
	}
	v := s.top.val
	s.top = s.top.next
	s.size--
	return v, true
}
```

**注意**

- 值接收者里修改字段**不会生效**（改的是副本），这是新手最常见的 bug 之一。
- **同一个类型的方法尽量统一用一种接收者**；只要有一个方法需要指针接收者，就全部用指针。
- 方法集规则：`T` 的方法集只包含值接收者方法；`*T` 包含全部方法。所以只有 `*T` 实现了包含指针接收者方法的接口。
- 包含 `sync.Mutex` 的结构体必须用指针接收者，否则每次调用都复制了一把新锁（`go vet` 会报 copylocks）。

=== method-value
name: 方法值与方法表达式
group: 结构体与方法
--- body
`obj.Method`（不加括号）得到一个**绑定了接收者**的函数值，叫方法值；`Type.Method` 得到一个把接收者当第一个参数的函数，叫方法表达式。

**写法**

```go
c := &Counter{}
inc := c.Inc     // 方法值：func()，已经绑定了 c
inc()
inc()            // c.n == 2

f := (*Counter).Inc // 方法表达式：func(*Counter)
f(c)
```

**例子：把方法当回调传出去**

```go
type Server struct{ hits int }

func (s *Server) handle(w http.ResponseWriter, r *http.Request) {
	s.hits++
}

mux := http.NewServeMux()
srv := &Server{}
mux.HandleFunc("/", srv.handle) // 方法值满足 func(w, r) 签名
```

`defer wg.Wait()`、`go w.run()`、`time.AfterFunc(d, t.flush)` 里的 `wg.Wait`、`t.flush` 都是方法值。

**注意**

- 方法值在**创建时就求值并保存了接收者**：值接收者会复制一份当时的值，之后修改原变量不会影响它。
- 对 nil 指针创建方法值不会立即 panic，调用时才可能 panic。
