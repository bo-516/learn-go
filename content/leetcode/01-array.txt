title: 两数之和
slug: two-sum
difficulty: 简单
category: 数组与切片
topics: 数组, 哈希表
go: map
--- desc
给定整数数组 `nums` 和目标值 `target`，找出**和为 target 的两个数**，返回它们的下标。保证恰好有一个答案，同一个元素不能用两次，下标顺序不限。

**示例**：`nums = [2,7,11,15], target = 9` → `[0,1]`（2 + 7 = 9）。

要求时间复杂度优于 O(n²)。
--- solution
package main

func twoSum(nums []int, target int) []int {
	// @solution
	seen := make(map[int]int, len(nums)) // 值 → 下标
	for i, v := range nums {
		if j, ok := seen[target-v]; ok {
			return []int{j, i}
		}
		seen[v] = i
	}
	return nil
	// @starter
	// return nil
	// @end
}
--- test
package main

import "testing"

func TestTwoSum(t *testing.T) {
	cases := []struct {
		nums   []int
		target int
	}{
		{[]int{2, 7, 11, 15}, 9},
		{[]int{3, 2, 4}, 6},
		{[]int{3, 3}, 6},
		{[]int{-1, -2, -3, -4, -5}, -8},
		{[]int{0, 4, 3, 0}, 0},
	}
	for _, c := range cases {
		got := twoSum(c.nums, c.target)
		if len(got) != 2 || got[0] == got[1] || got[0] < 0 || got[1] < 0 ||
			got[0] >= len(c.nums) || got[1] >= len(c.nums) || c.nums[got[0]]+c.nums[got[1]] != c.target {
			t.Errorf("twoSum(%v, %d) = %v", c.nums, c.target, got)
		}
	}
}
--- explain
边遍历边查表：对每个数 `v`，看 `target-v` 是否已经出现过。`j, ok := seen[k]` 是 map 的 **comma-ok** 写法——直接 `seen[k]` 在 key 不存在时返回零值 0，无法区分「不存在」和「下标为 0」。

`make(map[int]int, len(nums))` 预先分配容量，避免扩容。时间 O(n)，空间 O(n)。

title: 存在重复元素
slug: contains-duplicate
difficulty: 简单
category: 数组与切片
topics: 数组, 哈希表
go: map, struct{} 集合
--- desc
如果数组中有任何值出现**至少两次**，返回 `true`；所有元素都不相同则返回 `false`。

**示例**：`[1,2,3,1]` → `true`；`[1,2,3,4]` → `false`。
--- solution
package main

func containsDuplicate(nums []int) bool {
	// @solution
	seen := make(map[int]struct{}, len(nums))
	for _, v := range nums {
		if _, ok := seen[v]; ok {
			return true
		}
		seen[v] = struct{}{}
	}
	return false
	// @starter
	// return false
	// @end
}
--- test
package main

import "testing"

func TestContainsDuplicate(t *testing.T) {
	cases := []struct {
		nums []int
		want bool
	}{
		{[]int{1, 2, 3, 1}, true},
		{[]int{1, 2, 3, 4}, false},
		{[]int{1, 1, 1, 3, 3, 4, 3, 2, 4, 2}, true},
		{[]int{}, false},
		{[]int{-5}, false},
	}
	for _, c := range cases {
		if got := containsDuplicate(c.nums); got != c.want {
			t.Errorf("containsDuplicate(%v) = %v，期望 %v", c.nums, got, c.want)
		}
	}
}
--- explain
Go 没有内置的 Set，惯用法是 `map[T]struct{}`：`struct{}` 不占内存，比 `map[T]bool` 更省，语义也更明确。

也可以写成泛型函数，任何可比较类型都能用：

```go
func hasDup[T comparable](s []T) bool {
	seen := make(map[T]struct{}, len(s))
	for _, v := range s {
		if _, ok := seen[v]; ok {
			return true
		}
		seen[v] = struct{}{}
	}
	return false
}
```

另一种思路是先 `slices.Sort` 再比较相邻元素：O(n log n) 时间、O(1) 额外空间（但会修改入参）。

title: 移动零
slug: move-zeroes
difficulty: 简单
category: 数组与切片
topics: 数组, 双指针
go: 原地修改, 多重赋值
--- desc
把数组中所有的 `0` 移动到末尾，同时保持非零元素的相对顺序。必须**原地**修改，不能拷贝数组。

**示例**：`[0,1,0,3,12]` → `[1,3,12,0,0]`。
--- solution
package main

func moveZeroes(nums []int) {
	// @solution
	slow := 0 // [0, slow) 是已经处理好的非零元素
	for fast := range nums {
		if nums[fast] != 0 {
			nums[slow], nums[fast] = nums[fast], nums[slow]
			slow++
		}
	}
	// @starter
	// @end
}
--- test
package main

import (
	"slices"
	"testing"
)

func TestMoveZeroes(t *testing.T) {
	cases := []struct{ in, want []int }{
		{[]int{0, 1, 0, 3, 12}, []int{1, 3, 12, 0, 0}},
		{[]int{0}, []int{0}},
		{[]int{1, 2, 3}, []int{1, 2, 3}},
		{[]int{0, 0, 1}, []int{1, 0, 0}},
		{[]int{4, 0, -2, 0, 0, 7}, []int{4, -2, 7, 0, 0, 0}},
	}
	for _, c := range cases {
		in := slices.Clone(c.in)
		moveZeroes(in)
		if !slices.Equal(in, c.want) {
			t.Errorf("moveZeroes(%v) → %v，期望 %v", c.in, in, c.want)
		}
	}
}
--- explain
函数参数 `nums` 是切片头的拷贝，但它指向调用方的底层数组，所以对 `nums[i]` 的修改调用方能看到——这就是「原地」修改。

快慢双指针：`fast` 扫描每个元素，遇到非零就和 `slow` 位置交换。`a, b = b, a` 是 Go 的**多重赋值**，右边先全部求值再赋值，不需要临时变量。时间 O(n)，空间 O(1)。

title: 删除有序数组中的重复项
slug: remove-duplicates-from-sorted-array
difficulty: 简单
category: 数组与切片
topics: 数组, 双指针
go: 原地修改, 切片
--- desc
给定一个**非严格递增**的数组，原地删除重复元素，使每个元素只出现一次，返回新的长度 `k`。`nums` 的前 `k` 个元素应该是去重后的结果，后面的元素不重要。

**示例**：`[0,0,1,1,1,2,2,3,3,4]` → 返回 `5`，前 5 个元素为 `[0,1,2,3,4]`。
--- solution
package main

func removeDuplicates(nums []int) int {
	// @solution
	if len(nums) == 0 {
		return 0
	}
	k := 1
	for i := 1; i < len(nums); i++ {
		if nums[i] != nums[k-1] {
			nums[k] = nums[i]
			k++
		}
	}
	return k
	// @starter
	// return 0
	// @end
}
--- test
package main

import (
	"slices"
	"testing"
)

func TestRemoveDuplicates(t *testing.T) {
	cases := []struct{ in, want []int }{
		{[]int{1, 1, 2}, []int{1, 2}},
		{[]int{0, 0, 1, 1, 1, 2, 2, 3, 3, 4}, []int{0, 1, 2, 3, 4}},
		{[]int{7}, []int{7}},
		{[]int{-3, -3, -3}, []int{-3}},
		{[]int{1, 2, 3}, []int{1, 2, 3}},
	}
	for _, c := range cases {
		nums := slices.Clone(c.in)
		k := removeDuplicates(nums)
		if k != len(c.want) || !slices.Equal(nums[:k], c.want) {
			t.Errorf("removeDuplicates(%v) = %d, 前 k 个 = %v，期望 %v", c.in, k, nums[:min(k, len(nums))], c.want)
		}
	}
}
--- explain
因为数组有序，重复元素一定相邻。`k` 指向下一个要写入的位置，只有和最后写入的值不同时才写入。

在 Go 里调用方通常直接用 `nums = nums[:k]` 截取结果——切片截取不拷贝，只是改变切片头的长度。标准库也有现成的 `slices.Compact(nums)`，做的就是这件事。

title: 合并两个有序数组
slug: merge-sorted-array
difficulty: 简单
category: 数组与切片
topics: 数组, 双指针, 排序
go: 原地修改
--- desc
`nums1` 的前 `m` 个元素和 `nums2` 的 `n` 个元素都按非递减排列。`nums1` 的长度是 `m + n`，后 `n` 个位置是 0，用来放结果。把 `nums2` 合并进 `nums1`，使整体有序。

**示例**：`nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3` → `nums1 = [1,2,2,3,5,6]`。
--- solution
package main

func merge(nums1 []int, m int, nums2 []int, n int) {
	// @solution
	i, j, w := m-1, n-1, m+n-1
	for j >= 0 {
		if i >= 0 && nums1[i] > nums2[j] {
			nums1[w] = nums1[i]
			i--
		} else {
			nums1[w] = nums2[j]
			j--
		}
		w--
	}
	// @starter
	// @end
}
--- test
package main

import (
	"slices"
	"testing"
)

func TestMerge(t *testing.T) {
	cases := []struct {
		nums1 []int
		m     int
		nums2 []int
		want  []int
	}{
		{[]int{1, 2, 3, 0, 0, 0}, 3, []int{2, 5, 6}, []int{1, 2, 2, 3, 5, 6}},
		{[]int{1}, 1, []int{}, []int{1}},
		{[]int{0}, 0, []int{1}, []int{1}},
		{[]int{4, 5, 6, 0, 0, 0}, 3, []int{1, 2, 3}, []int{1, 2, 3, 4, 5, 6}},
		{[]int{-1, 0, 0, 3, 3, 3, 0, 0, 0}, 6, []int{1, 2, 2}, []int{-1, 0, 0, 1, 2, 2, 3, 3, 3}},
	}
	for _, c := range cases {
		nums1 := slices.Clone(c.nums1)
		merge(nums1, c.m, c.nums2, len(c.nums2))
		if !slices.Equal(nums1, c.want) {
			t.Errorf("merge(%v, %d, %v) → %v，期望 %v", c.nums1, c.m, c.nums2, nums1, c.want)
		}
	}
}
--- explain
**从后往前**合并：`nums1` 末尾是空位，每次把两边较大的数放到最后，不会覆盖还没处理的元素，不需要额外空间。

当 `nums2` 处理完时就可以停止——`nums1` 剩下的元素本来就在正确的位置。如果反过来是 `nums1` 先处理完，循环会继续把 `nums2` 剩下的元素依次放进去（也可以直接 `copy(nums1[:j+1], nums2[:j+1])`）。时间 O(m+n)，空间 O(1)。

title: 买卖股票的最佳时机
slug: best-time-to-buy-and-sell-stock
difficulty: 简单
category: 数组与切片
topics: 数组, 动态规划
go: 内置 min/max
--- desc
`prices[i]` 是一支股票第 i 天的价格。你只能选择某一天买入、之后的某一天卖出（只交易一次），返回能获得的最大利润；无法获利返回 0。

**示例**：`[7,1,5,3,6,4]` → `5`（第 2 天以 1 买入，第 5 天以 6 卖出）；`[7,6,4,3,1]` → `0`。
--- solution
package main

import "math"

func maxProfit(prices []int) int {
	// @solution
	lowest, best := math.MaxInt, 0
	for _, p := range prices {
		lowest = min(lowest, p)
		best = max(best, p-lowest)
	}
	return best
	// @starter
	// return 0
	// @end
}
--- test
package main

import "testing"

func TestMaxProfit(t *testing.T) {
	cases := []struct {
		prices []int
		want   int
	}{
		{[]int{7, 1, 5, 3, 6, 4}, 5},
		{[]int{7, 6, 4, 3, 1}, 0},
		{[]int{1}, 0},
		{[]int{2, 4, 1}, 2},
		{[]int{3, 2, 6, 5, 0, 3}, 4},
	}
	for _, c := range cases {
		if got := maxProfit(c.prices); got != c.want {
			t.Errorf("maxProfit(%v) = %d，期望 %d", c.prices, got, c.want)
		}
	}
}
--- explain
遍历时记录**到目前为止的最低价**，每天都算一下「今天卖出能赚多少」，取最大值。

Go 1.21 起 `min`、`max` 是内置函数，支持任意可比较大小的类型和多个参数（`max(a, b, c)`），不用再自己写辅助函数。`math.MaxInt` 是 int 的最大值，常用作「无穷大」的初始值。时间 O(n)，空间 O(1)。

给定长度为 n 的数组 `nums`，返回长度为 2n 的数组 `ans`，满足 `ans[i] == nums[i]` 且 `ans[i + n] == nums[i]`，也就是把 `nums` 自己和自己拼起来。

--- solution
package main

func getConcatenation(nums []int) []int {
	// @solution
	ans := make([]int, 0, 2*len(nums))
	ans = append(ans, nums...)
	return append(ans, nums...)
	// @starter

	// @end
}

	"slices"
	"testing"
)

func TestGetConcatenation(t *testing.T) {
	cases := []struct{ in, want []int }{
		{[]int{1, 2, 1}, []int{1, 2, 1, 1, 2, 1}},
		{[]int{1, 3, 2, 1}, []int{1, 3, 2, 1, 1, 3, 2, 1}},
		{[]int{5}, []int{5, 5}},

		in := slices.Clone(c.in)
		got := getConcatenation(in)

title: 杨辉三角
slug: pascals-triangle
difficulty: 简单
category: 数组与切片
topics: 数组, 动态规划
go: 切片
--- desc
给定非负整数 `numRows`，生成杨辉三角的前 `numRows` 行。每个数等于它左上方和右上方两个数之和，每行首尾都是 1。

**示例**：`numRows = 5` → `[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]`。
--- solution
package main

func generate(numRows int) [][]int {
	// @solution
	rows := make([][]int, numRows)
	for i := range rows {
		row := make([]int, i+1)
		row[0], row[i] = 1, 1
		for j := 1; j < i; j++ {
			row[j] = rows[i-1][j-1] + rows[i-1][j]
		}
		rows[i] = row
	}
	return rows
	// @starter
	// return nil
	// @end
}
--- test
package main

import (
	"slices"
	"testing"
)

func TestGenerate(t *testing.T) {
	want := [][]int{{1}, {1, 1}, {1, 2, 1}, {1, 3, 3, 1}, {1, 4, 6, 4, 1}}
	got := generate(5)
	if !slices.EqualFunc(got, want, slices.Equal[[]int]) {
		t.Fatalf("generate(5) = %v", got)
	}
	if got := generate(1); !slices.EqualFunc(got, [][]int{{1}}, slices.Equal[[]int]) {
		t.Fatalf("generate(1) = %v", got)
	}
	if row := generate(30)[29]; row[15] != 77558760 {
		t.Fatalf("第 30 行中间的数 = %d", row[15])
	}
}
--- explain
Go 没有真正的二维数组切片，`[][]int` 是「切片的切片」：外层切片的每个元素都是一个独立的 `[]int`，需要分别 `make`。每行长度不同（锯齿状）在 Go 里很自然。

`row[0], row[i] = 1, 1` 是多重赋值；当 `i == 0` 时两者是同一个位置，也没有问题。时间 O(n²)。

title: 二分查找
slug: binary-search
difficulty: 简单
category: 数组与切片
topics: 数组, 二分查找
go: switch, 整数运算
--- desc
在一个**升序**且元素不重复的数组中查找 `target`，存在返回下标，否则返回 `-1`。要求 O(log n)。

**示例**：`nums = [-1,0,3,5,9,12], target = 9` → `4`；`target = 2` → `-1`。
--- solution
package main

func search(nums []int, target int) int {
	// @solution
	lo, hi := 0, len(nums)-1
	for lo <= hi {
		mid := lo + (hi-lo)/2
		switch {
		case nums[mid] == target:
			return mid
		case nums[mid] < target:
			lo = mid + 1
		default:
			hi = mid - 1
		}
	}
	return -1
	// @starter
	// return -1
	// @end
}
--- test
package main

import "testing"

func TestSearch(t *testing.T) {
	nums := []int{-1, 0, 3, 5, 9, 12}
	for i, v := range nums {
		if got := search(nums, v); got != i {
			t.Errorf("search(%v, %d) = %d，期望 %d", nums, v, got, i)
		}
	}
	for _, v := range []int{2, -5, 13} {
		if got := search(nums, v); got != -1 {
			t.Errorf("search(%v, %d) = %d，期望 -1", nums, v, got)
		}
	}
	if search([]int{5}, 5) != 0 || search([]int{}, 1) != -1 {
		t.Error("边界情况")
	}
	big := make([]int, 100000)
	for i := range big {
		big[i] = i * 3
	}
	if search(big, 299997) != 99999 || search(big, 299998) != -1 {
		t.Error("大数组")
	}
}
--- explain
`mid := lo + (hi-lo)/2` 而不是 `(lo+hi)/2`：后者在 lo、hi 都很大时可能溢出（Java/C 里的经典 bug，Go 的 int 在 64 位平台上是 64 位，几乎不会遇到，但写法值得养成习惯）。

`switch` 不带表达式时相当于 `switch true`，按顺序匹配第一个为真的 case，比 if-else 链更整齐。

标准库里可以直接用 `slices.BinarySearch(nums, target)`，返回插入位置和是否找到。

slug: squares-of-a-sorted-array
difficulty: 简单
category: 数组与切片

--- desc
给定一个按**非递减**顺序排列的整数数组（可能有负数），返回每个数的平方组成的新数组，也按非递减顺序排列。要求 O(n)。

**示例**：`[-4,-1,0,3,10]` → `[0,1,9,16,100]`。
--- solution
package main

func sortedSquares(nums []int) []int {
	// @solution
	n := len(nums)
	out := make([]int, n)
	l, r := 0, n-1
	for w := n - 1; w >= 0; w-- {
		a, b := nums[l]*nums[l], nums[r]*nums[r]
		if a > b {
			out[w] = a
			l++
		} else {
			out[w] = b
			r--
		}
	}
	return out
	// @starter
	// return nil
	// @end
}
--- test

	"slices"
	"testing"

		{[]int{-5, -3, -1}, []int{1, 9, 25}},
		{[]int{1}, []int{1}},
	}
	for _, c := range cases {
		if got := sortedSquares(c.in); !slices.Equal(got, c.want) {

}
--- explain
平方最大的数一定在数组的**两端**（最负的或最正的），所以用左右两个指针，每次把较大的平方从结果的末尾往前填。

注意这里用的是 `make([]int, n)`（长度为 n，可以直接按下标写入），而不是 `make([]int, 0, n)`（长度为 0，只能 append）。两者的区别是 Go 新手最常见的困惑之一。

category: 数组与切片
topics: 数组, 数学
go: 切片
--- desc
用数组表示一个非负整数，最高位在数组开头，每个元素只存一位数字。返回这个数加一之后的数组。

**示例**：`[1,2,3]` → `[1,2,4]`；`[9,9]` → `[1,0,0]`。
--- solution
package main

func plusOne(digits []int) []int {
	// @solution
	for i := len(digits) - 1; i >= 0; i-- {
		if digits[i] < 9 {
			digits[i]++
			return digits
		}
		digits[i] = 0
	}
	return append([]int{1}, digits...)
	// @starter
	// return digits
	// @end
}
--- test
package main

import (
	"slices"
	"testing"
)

func TestPlusOne(t *testing.T) {
	cases := []struct{ in, want []int }{
		{[]int{1, 2, 3}, []int{1, 2, 4}},
		{[]int{4, 3, 2, 1}, []int{4, 3, 2, 2}},
		{[]int{9}, []int{1, 0}},
		{[]int{9, 9, 9}, []int{1, 0, 0, 0}},
		{[]int{1, 9, 9}, []int{2, 0, 0}},
		{[]int{0}, []int{1}},
	}
	for _, c := range cases {
		if got := plusOne(slices.Clone(c.in)); !slices.Equal(got, c.want) {
			t.Errorf("plusOne(%v) = %v，期望 %v", c.in, got, c.want)
		}
	}
}

`append([]int{1}, digits...)` 是 Go 里在切片**头部插入**的常见写法（会分配新数组）。也可以用 `slices.Insert(digits, 0, 1)`。

title: 只出现一次的数字
slug: single-number
difficulty: 简单
category: 数组与切片
topics: 数组, 位运算
go: 位运算
--- desc
数组中除了某个元素只出现一次以外，其余每个元素都恰好出现两次。找出那个只出现一次的元素。要求线性时间、常数额外空间。

**示例**：`[4,1,2,1,2]` → `4`。
--- solution
package main

func singleNumber(nums []int) int {
	// @solution
	x := 0
	for _, v := range nums {
		x ^= v
	}
	return x
	// @starter
	// return 0
	// @end
}
--- test
package main

import "testing"

func TestSingleNumber(t *testing.T) {
	cases := []struct {
		nums []int
		want int
	}{
		{[]int{2, 2, 1}, 1},
		{[]int{4, 1, 2, 1, 2}, 4},
		{[]int{1}, 1},
		{[]int{-3, 7, 7}, -3},
		{[]int{0, 5, 5, 9, 9}, 0},
	}
	for _, c := range cases {
		if got := singleNumber(c.nums); got != c.want {
			t.Errorf("singleNumber(%v) = %d，期望 %d", c.nums, got, c.want)
		}
	}
}
--- explain
异或运算的性质：`a ^ a == 0`、`a ^ 0 == a`，并且满足交换律和结合律。把所有数异或起来，成对的数互相抵消，剩下的就是只出现一次的数。

Go 的位运算符：`&` 与、`|` 或、`^` 异或（一元时是按位取反）、`&^` 清位（AND NOT）、`<<` / `>>` 移位。

=== lc-169
no: 169
title: 多数元素
slug: majority-element
difficulty: 简单
category: 数组与切片
topics: 数组, 计数
go: switch, 多重赋值
--- desc
找出数组中出现次数**超过一半**的元素（保证存在）。尝试 O(n) 时间、O(1) 空间。

**示例**：`[2,2,1,1,1,2,2]` → `2`。
--- solution
package main

func majorityElement(nums []int) int {
	// @solution
	candidate, count := 0, 0
	for _, v := range nums {
		switch {
		case count == 0:
			candidate, count = v, 1
		case v == candidate:
			count++
		default:
			count--
		}
	}
	return candidate
	// @starter
	// return 0
	// @end
}
--- test
package main

import "testing"

func TestMajorityElement(t *testing.T) {
	cases := []struct {
		nums []int
		want int
	}{
		{[]int{3, 2, 3}, 3},
		{[]int{2, 2, 1, 1, 1, 2, 2}, 2},
		{[]int{1}, 1},
		{[]int{6, 5, 5}, 5},
		{[]int{-1, -1, 2, -1, 3}, -1},
	}
	for _, c := range cases {
		if got := majorityElement(c.nums); got != c.want {
			t.Errorf("majorityElement(%v) = %d，期望 %d", c.nums, got, c.want)
		}
	}
}
--- explain
**摩尔投票法**：把多数元素看成一方，其他所有元素看成另一方，两两抵消。因为多数元素超过一半，抵消到最后剩下的一定是它。

用 map 计数也能做（O(n) 空间），或者排序后取中间的元素（O(n log n)）。

=== lc-350
no: 350
title: 两个数组的交集 II
slug: intersection-of-two-arrays-ii
difficulty: 简单
category: 数组与切片
topics: 数组, 哈希表
go: map, 多重赋值
--- desc
返回两个数组的交集，结果中每个元素出现的次数，等于它在两个数组中出现次数的**较小值**。结果顺序不限。

**示例**：`nums1 = [1,2,2,1], nums2 = [2,2]` → `[2,2]`；`nums1 = [4,9,5], nums2 = [9,4,9,8,4]` → `[4,9]`。
--- solution
package main

func intersect(nums1 []int, nums2 []int) []int {
	// @solution
	if len(nums1) > len(nums2) {
		nums1, nums2 = nums2, nums1 // 用较小的数组建表
	}
	count := make(map[int]int, len(nums1))
	for _, v := range nums1 {
		count[v]++
	}
	var out []int
	for _, v := range nums2 {
		if count[v] > 0 {
			out = append(out, v)
			count[v]--
		}
	}
	return out
	// @starter
	// return nil
	// @end
}
--- test
package main

import (
	"slices"
	"testing"
)

func TestIntersect(t *testing.T) {
	cases := []struct{ a, b, want []int }{
		{[]int{1, 2, 2, 1}, []int{2, 2}, []int{2, 2}},
		{[]int{4, 9, 5}, []int{9, 4, 9, 8, 4}, []int{4, 9}},
		{[]int{1, 2}, []int{3}, nil},
		{[]int{3, 1, 2, 3, 3}, []int{3, 3}, []int{3, 3}},
	}
	for _, c := range cases {
		got := intersect(c.a, c.b)
		slices.Sort(got)
		if len(got) != len(c.want) || (len(got) > 0 && !slices.Equal(got, c.want)) {
			t.Errorf("intersect(%v, %v) = %v，期望 %v", c.a, c.b, got, c.want)
		}
	}
}
--- explain
`count[v]++` 在 key 不存在时也能工作：读取不存在的 key 返回零值 0，加一后写回。这是 Go map 「零值可用」的典型用法。

`nums1, nums2 = nums2, nums1` 交换的只是两个切片头，开销很小。用较小的数组建表能节省内存。
