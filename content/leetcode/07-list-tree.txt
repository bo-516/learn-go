title: 两数相加
slug: add-two-numbers
difficulty: 中等
category: 链表
topics: 链表, 数学
go: 结构体与指针, 整数运算
--- desc
两个非空链表表示两个非负整数，数字按**逆序**存储（个位在链表头），每个节点存一位数字。把两个数相加，以同样的形式返回表示和的链表。

**示例**：`[2,4,3] + [5,6,4]` → `[7,0,8]`（342 + 465 = 807）；`[9,9,9,9,9,9,9] + [9,9,9,9]` → `[8,9,9,9,0,0,0,1]`。
--- solution
package main

type ListNode struct {
	Val  int
	Next *ListNode
}

func addTwoNumbers(l1 *ListNode, l2 *ListNode) *ListNode {
	// @solution
	dummy := &ListNode{}
	tail, carry := dummy, 0
	for l1 != nil || l2 != nil || carry > 0 {
		sum := carry
		if l1 != nil {
			sum += l1.Val
			l1 = l1.Next
		}
		if l2 != nil {
			sum += l2.Val
			l2 = l2.Next
		}
		tail.Next = &ListNode{Val: sum % 10}
		tail = tail.Next
		carry = sum / 10
	}
	return dummy.Next
	// @starter
	// return nil
	// @end
}
--- test

		{[]int{2, 4, 3}, []int{5, 6, 4}, []int{7, 0, 8}},
		{[]int{0}, []int{0}, []int{0}},
		{[]int{9, 9, 9, 9, 9, 9, 9}, []int{9, 9, 9, 9}, []int{8, 9, 9, 9, 0, 0, 0, 1}},
		{[]int{5}, []int{5}, []int{0, 1}},
		{[]int{1, 8}, []int{0}, []int{1, 8}},
	}
	for _, c := range cases {
		if got := values(addTwoNumbers(build(c.a...), build(c.b...))); !slices.Equal(got, c.want) {
			t.Errorf("addTwoNumbers(%v, %v) = %v，期望 %v", c.a, c.b, got, c.want)

--- explain
**思路**

数字是逆序存的，链表头就是个位，正好可以从头开始模拟竖式加法：两个链表同时往后走，对应位相加再加上进位，当前位是 `sum % 10`，新的进位是 `sum / 10`。

**代码讲解**

1. `dummy := &ListNode{}`：哨兵节点，结果链表挂在它后面，不用特判“第一个节点”。
2. `tail, carry := dummy, 0`：tail 指向结果的最后一个节点。
3. `for l1 != nil || l2 != nil || carry > 0`：三个条件任一成立就继续。把 `carry > 0` 放进条件，最高位的进位（如 5 + 5 = 10）就不用在循环后单独处理。
4. 链表走完的那一边当作 0：只在不为 nil 时累加并后移。
5. `tail.Next = &ListNode{Val: sum % 10}`：新建节点并接上。

**易错点**

- 忘记最后的进位，`[5] + [5]` 会得到 `[0]`。
- 不能把链表转成整数相加：链表长度可达 100，远超 int64。

**复杂度**

时间 O(max(m, n))，空间 O(1)（不算结果）。

--- desc
删除链表的**倒数第 n 个**节点，返回链表的头节点。保证 n 不超过链表长度。尝试只遍历一次。

**示例**：`[1,2,3,4,5], n = 2` → `[1,2,3,5]`；`[1], n = 1` → `[]`。
--- solution
package main

type ListNode struct {
	Val  int
	Next *ListNode
}

func removeNthFromEnd(head *ListNode, n int) *ListNode {
	// @solution
	dummy := &ListNode{Next: head}
	fast, slow := head, dummy
	for range n {
		fast = fast.Next // fast 先走 n 步
	}
	for fast != nil {
		fast, slow = fast.Next, slow.Next
	}
	// 现在 slow 是倒数第 n 个节点的前一个
	slow.Next = slow.Next.Next
	return dummy.Next
	// @starter
	// return head
	// @end
}

--- explain
**思路**

快慢指针保持固定间距：先让 fast 走 n 步，然后 fast、slow 一起走，fast 走到末尾（nil）时，slow 离末尾正好 n 步。为了删除节点，需要停在它的**前一个**节点，所以 slow 从哨兵节点出发。

**代码讲解**

1. `dummy := &ListNode{Next: head}`：哨兵节点，删除头节点时不用特判。
2. `fast, slow := head, dummy`：slow 比 fast 落后一步起跑，最后正好停在待删节点的前一个。
3. `for range n`：Go 1.22 的 range 整数写法，只是重复 n 次。
4. `fast, slow = fast.Next, slow.Next`：多重赋值，两个指针同时前进。
5. `slow.Next = slow.Next.Next`：跳过待删节点。
6. 返回 `dummy.Next`：头节点可能已经被删了。

**易错点**

- 不用哨兵节点时，删除头节点（`n == 长度`）要单独处理，容易漏。
- 也可以先遍历一次求长度 L，再走到第 L−n 个节点，需要两次遍历。

**复杂度**

时间 O(L)，空间 O(1)。

title: 两两交换链表中的节点
slug: swap-nodes-in-pairs
difficulty: 中等
category: 链表
topics: 链表, 递归
go: 结构体与指针, 多重赋值
--- desc
两两交换链表中相邻的节点，返回交换后的头节点。必须交换**节点本身**，不能只修改节点的值。

**示例**：`[1,2,3,4]` → `[2,1,4,3]`；`[1,2,3]` → `[2,1,3]`；`[]` → `[]`。
--- solution
package main

type ListNode struct {
	Val  int
	Next *ListNode
}

func swapPairs(head *ListNode) *ListNode {
	// @solution
	dummy := &ListNode{Next: head}
	prev := dummy
	for prev.Next != nil && prev.Next.Next != nil {
		a, b := prev.Next, prev.Next.Next
		// prev → a → b → rest  变成  prev → b → a → rest
		a.Next = b.Next
		b.Next = a
		prev.Next = b
		prev = a // a 现在是这一对的第二个，下一对接在它后面
	}
	return dummy.Next
	// @starter
	// return head
	// @end
}
--- test
package main

import (
	"slices"
	"testing"
)

func build(vals ...int) *ListNode {
	dummy := &ListNode{}
	cur := dummy
	for _, v := range vals {
		cur.Next = &ListNode{Val: v}
		cur = cur.Next
	}
	return dummy.Next
}

func TestSwapPairs(t *testing.T) {
	cases := []struct{ in, want []int }{
		{[]int{1, 2, 3, 4}, []int{2, 1, 4, 3}},
		{nil, nil},
		{[]int{1}, []int{1}},
		{[]int{1, 2, 3}, []int{2, 1, 3}},
		{[]int{1, 2, 3, 4, 5, 6}, []int{2, 1, 4, 3, 6, 5}},
	}
	for _, c := range cases {
		head := build(c.in...)
		nodes := map[int]*ListNode{} // 记录原来的节点，检查是不是交换了节点而不是改值
		for n := head; n != nil; n = n.Next {
			nodes[n.Val] = n
		}
		var got []int
		for n := swapPairs(head); n != nil; n = n.Next {
			if nodes[n.Val] != n {
				t.Fatalf("swapPairs(%v)：值 %d 所在的节点不是原来的节点，需要交换节点本身", c.in, n.Val)
			}
			got = append(got, n.Val)
		}
		if !slices.Equal(got, c.want) {
			t.Errorf("swapPairs(%v) = %v，期望 %v", c.in, got, c.want)
		}
	}
}
--- explain
**思路**

每次处理一对节点 `a → b`，把它们改成 `b → a`，并接好前后的指针。需要知道这一对的**前一个节点** prev（用来接上 b），所以从哨兵节点开始。

**代码讲解**

1. `dummy := &ListNode{Next: head}`、`prev := dummy`：第一对的前一个节点是哨兵。
2. `for prev.Next != nil && prev.Next.Next != nil`：后面至少还有两个节点才交换；剩一个就保持原样。
3. `a, b := prev.Next, prev.Next.Next`：取出这一对。
4. 三步改指针（顺序很重要）：
   - `a.Next = b.Next`：a 接上后面的部分；
   - `b.Next = a`：b 指向 a；
   - `prev.Next = b`：前面接上 b。
5. `prev = a`：a 现在在这一对的后面，是下一对的“前一个节点”。

**易错点**

- 先执行 `b.Next = a` 会丢掉 b 后面的链表。改指针前先想清楚哪些引用会丢失，必要时先存下来。
- 只交换值（`a.Val, b.Val = b.Val, a.Val`）能得到正确的序列，但题目不允许，测试也会检查节点身份。

**复杂度**

时间 O(n)，空间 O(1)。

**延伸**

递归写法很简洁：`b := head.Next; head.Next = swapPairs(b.Next); b.Next = head; return b`。

title: 环形链表 II
slug: linked-list-cycle-ii
difficulty: 中等
category: 链表
topics: 链表, 双指针, 哈希表
go: 结构体与指针, 多重赋值
--- desc
给定链表的头节点 `head`，返回链表**开始入环的第一个节点**；如果链表无环，返回 nil。不允许修改链表，尝试只用 O(1) 额外空间。

**示例**：`3 → 2 → 0 → -4`，且 `-4` 指回 `2` → 返回值为 2 的节点。
--- solution
package main

type ListNode struct {
	Val  int
	Next *ListNode
}

func detectCycle(head *ListNode) *ListNode {
	// @solution
	slow, fast := head, head
	for fast != nil && fast.Next != nil {
		slow, fast = slow.Next, fast.Next.Next
		if slow == fast { // 相遇，说明有环
			p := head
			for p != slow { // 从头和相遇点同时走，再次相遇的地方就是入口
				p, slow = p.Next, slow.Next
			}
			return p
		}
	}
	return nil
	// @starter
	// return nil
	// @end
}
--- test
package main

import "testing"

// build 构造链表，pos 是尾节点指向的节点下标（-1 表示无环），同时返回所有节点
func build(pos int, vals ...int) (*ListNode, []*ListNode) {
	nodes := make([]*ListNode, len(vals))
	for i, v := range vals {
		nodes[i] = &ListNode{Val: v}
		if i > 0 {
			nodes[i-1].Next = nodes[i]
		}
	}
	if pos >= 0 {
		nodes[len(nodes)-1].Next = nodes[pos]
	}
	if len(nodes) == 0 {
		return nil, nil
	}
	return nodes[0], nodes
}

func TestDetectCycle(t *testing.T) {
	cases := []struct {
		vals []int
		pos  int
	}{
		{[]int{3, 2, 0, -4}, 1},
		{[]int{1, 2}, 0},
		{[]int{1}, -1},
		{[]int{1, 2, 3, 4, 5, 6}, 3},
		{[]int{1}, 0},
		{[]int{1, 2, 3}, -1},
		{nil, -1},
	}
	for _, c := range cases {
		head, nodes := build(c.pos, c.vals...)
		var want *ListNode
		if c.pos >= 0 {
			want = nodes[c.pos]
		}
		if got := detectCycle(head); got != want {
			t.Errorf("detectCycle(%v, pos=%d) 返回的节点不对", c.vals, c.pos)
		}
	}
}
--- explain
**思路**

两步：

1. 快慢指针判断有没有环（同「环形链表」）。
2. 相遇后，让一个指针 p 回到链表头，p 和 slow **每次各走一步**，它们再次相遇的节点就是环的入口。

**为什么第 2 步成立**：设链表头到入口距离为 a，入口到相遇点距离为 b，环长为 c。相遇时 slow 走了 `a + b`，fast 走了 `2(a + b)`，fast 比 slow 多走了整数圈：`a + b = k·c`，即 `a = k·c − b`。从相遇点再走 a 步，等于先走 `c − b` 回到入口、再绕 k−1 圈，正好停在入口；而从头走 a 步也正好到入口。

**代码讲解**

1. `slow, fast = slow.Next, fast.Next.Next`：多重赋值同时移动两个指针。
2. `if slow == fast`：比较的是**指针**（节点地址）。
3. `p := head`，然后 `for p != slow` 同步前进，返回相遇点。

**易错点**

- 用 `map[*ListNode]bool` 记录访问过的节点也能找到入口（第一个重复访问的节点），简单但空间 O(n)。
- 第二阶段两个指针都是**每次一步**。

**复杂度**

时间 O(n)，空间 O(1)。

title: 二叉树的层序遍历
slug: binary-tree-level-order-traversal
difficulty: 中等
category: 二叉树
topics: 树, 广度优先搜索
go: 切片当队列, 二维切片
--- desc
给定二叉树的根节点，返回节点值的**层序遍历**结果（逐层地，从左到右访问所有节点），每一层是一个切片。

**示例**：`[3,9,20,null,null,15,7]` → `[[3],[9,20],[15,7]]`。
--- solution
package main

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

func levelOrder(root *TreeNode) [][]int {
	// @solution
	var res [][]int
	if root == nil {
		return res
	}
	queue := []*TreeNode{root}
	for len(queue) > 0 {
		n := len(queue) // 当前这一层有 n 个节点
		level := make([]int, 0, n)
		for i := 0; i < n; i++ {
			node := queue[i]
			level = append(level, node.Val)
			if node.Left != nil {
				queue = append(queue, node.Left)
			}
			if node.Right != nil {
				queue = append(queue, node.Right)
			}
		}
		queue = queue[n:] // 这一层出队
		res = append(res, level)
	}
	return res
	// @starter
	// return nil
	// @end
}
--- test
package main

import (
	"fmt"
	"testing"
)

// build 按层序构造二叉树，nil 表示空节点
func build(vals ...any) *TreeNode {
	if len(vals) == 0 || vals[0] == nil {
		return nil
	}
	root := &TreeNode{Val: vals[0].(int)}
	queue := []*TreeNode{root}
	for i := 1; len(queue) > 0 && i < len(vals); i += 2 {
		n := queue[0]
		queue = queue[1:]
		if vals[i] != nil {
			n.Left = &TreeNode{Val: vals[i].(int)}
			queue = append(queue, n.Left)
		}
		if i+1 < len(vals) && vals[i+1] != nil {
			n.Right = &TreeNode{Val: vals[i+1].(int)}
			queue = append(queue, n.Right)
		}
	}
	return root
}

func TestLevelOrder(t *testing.T) {
	cases := []struct {
		tree []any
		want string
	}{
		{[]any{3, 9, 20, nil, nil, 15, 7}, "[[3] [9 20] [15 7]]"},
		{[]any{1}, "[[1]]"},
		{nil, "[]"},
		{[]any{1, 2, 3, 4, nil, nil, 5}, "[[1] [2 3] [4 5]]"},
		{[]any{1, 2, nil, 3, nil, 4}, "[[1] [2] [3] [4]]"},
	}
	for _, c := range cases {
		if got := fmt.Sprint(levelOrder(build(c.tree...))); got != c.want {
			t.Errorf("levelOrder(%v) = %s，期望 %s", c.tree, got, c.want)
		}
	}
}
--- explain
**思路**

广度优先搜索（BFS）用**队列**：根节点入队；每轮先记下队列当前的长度 n，这 n 个节点就是同一层的，依次出队、记录值，并把它们的孩子入队。

**代码讲解**

1. `queue := []*TreeNode{root}`：用切片当队列，`append` 入队，`queue[n:]` 批量出队。
2. `n := len(queue)`：**在处理这一层之前**记下长度。循环过程中会往队列里追加下一层的节点，所以不能在循环条件里直接用 `len(queue)`。
3. `level := make([]int, 0, n)`：这一层正好有 n 个值，预分配容量。
4. 内层 `for i := 0; i < n; i++` 只处理前 n 个，孩子追加到后面。
5. `queue = queue[n:]`：一次性去掉这一层。
6. `res = append(res, level)`：二维切片追加一行。

**易错点**

- 用 `queue[1:]` 不断出队时，底层数组前面的空间不会被回收，但每次 append 扩容时会把剩余元素复制到新数组，所以内存不会无限增长。
- 也可以用 DFS：带着深度递归，`res[depth] = append(res[depth], val)`。

**复杂度**

时间 O(n)，空间 O(n)（队列最多存一层的节点，最坏约 n/2）。

--- desc
判断一棵二叉树是否是有效的二叉搜索树（BST）：

- 节点的左子树只包含**小于**当前节点的数；
- 节点的右子树只包含**大于**当前节点的数；
- 左右子树也都是二叉搜索树。

**示例**：`[2,1,3]` → `true`；`[5,1,4,null,null,3,6]` → `false`（右子树里的 3 比根 5 小）。
--- solution
package main

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

func isValidBST(root *TreeNode) bool {
	// @solution
	// valid 检查 n 为根的子树里所有值都在开区间 (lo.Val, hi.Val) 内，nil 表示这一侧没有限制
	var valid func(n, lo, hi *TreeNode) bool
	valid = func(n, lo, hi *TreeNode) bool {
		if n == nil {
			return true
		}
		if lo != nil && n.Val <= lo.Val || hi != nil && n.Val >= hi.Val {
			return false
		}
		return valid(n.Left, lo, n) && valid(n.Right, n, hi)
	}
	return valid(root, nil, nil)
	// @starter
	// return false
	// @end
}

		queue = queue[1:]
		if vals[i] != nil {
			n.Left = &TreeNode{Val: vals[i].(int)}
			queue = append(queue, n.Left)
		}
		if i+1 < len(vals) && vals[i+1] != nil {
			n.Right = &TreeNode{Val: vals[i+1].(int)}
			queue = append(queue, n.Right)
		}
	}
	return root
}

		tree []any
		want bool
	}{

		{[]any{5, 1, 4, nil, nil, 3, 6}, false},
		{[]any{5, 4, 6, nil, nil, 3, 7}, false},
		{[]any{1, 1}, false},
		{[]any{1}, true},
		{[]any{2147483647}, true},
		{[]any{3, 1, 5, 0, 2, 4, 6}, true},
	}
	for _, c := range cases {
		if got := isValidBST(build(c.tree...)); got != c.want {

		}

--- explain
**思路**

只比较节点和它的左右孩子是不够的：`[5, 4, 6, null, null, 3, 7]` 里 3 是 6 的左孩子（3 < 6 没问题），但它在 5 的右子树里，必须大于 5。正确做法是递归时**向下传递取值范围**：进入左子树时上界变成当前节点，进入右子树时下界变成当前节点。

**代码讲解**

1. `valid(n, lo, hi *TreeNode)`：用**节点指针**表示边界，`nil` 表示没有限制。这样不需要用 `math.MinInt` 之类的哨兵值，也就不用担心节点值恰好等于哨兵。
2. 递归闭包要先 `var` 声明再赋值。
3. `lo != nil && n.Val <= lo.Val || hi != nil && n.Val >= hi.Val`：Go 里 `&&` 的优先级高于 `||`，所以这就是 `(...) || (...)`。为了可读性也可以加上括号。
4. 等于边界也不合法（BST 不允许重复值），所以用 `<=` 和 `>=`。
5. `valid(n.Left, lo, n) && valid(n.Right, n, hi)`：左子树的上界收紧为 n，右子树的下界收紧为 n。

**易错点**

- 只比较父子关系（前面的反例）。
- 用 `math.MinInt64` 做初始下界时，节点值正好是这个数会被误判。

**复杂度**

时间 O(n)，空间 O(h)。

**延伸**

另一种方法：BST 的**中序遍历一定严格递增**，遍历时记录上一个值，发现不递增就返回 false。

给定二叉搜索树的根节点 `root` 和整数 `k`，返回树中第 k 小的元素（k 从 1 开始计数）。

**示例**：`root = [3,1,4,null,2], k = 1` → `1`；`root = [5,3,6,2,4,null,null,1], k = 3` → `3`。
--- solution
package main

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

func kthSmallest(root *TreeNode, k int) int {
	// @solution
	var stack []*TreeNode
	cur := root
	for cur != nil || len(stack) > 0 {
		for cur != nil {
			stack = append(stack, cur)
			cur = cur.Left
		}
		cur = stack[len(stack)-1]
		stack = stack[:len(stack)-1]
		k-- // 中序遍历按从小到大的顺序访问
		if k == 0 {
			return cur.Val
		}
		cur = cur.Right
	}
	return -1
	// @starter
	// return 0
	// @end
}

import "testing"

		queue = queue[1:]

			n.Left = &TreeNode{Val: vals[i].(int)}
			queue = append(queue, n.Left)

**思路**

二叉搜索树的**中序遍历**（左 → 根 → 右）正好按从小到大的顺序访问节点。所以做中序遍历，访问到第 k 个节点时就是答案，然后**立刻返回**，不用遍历整棵树。

**代码讲解**

1. 用显式栈做迭代中序遍历（和「二叉树的中序遍历」相同的模板）：一路向左压栈，弹出访问，再转向右子树。

**易错点**

- 先把整棵树中序遍历到切片里再取 `vals[k-1]` 也可以，但不能提前结束，空间 O(n)。

**复杂度**

时间 O(h + k)，空间 O(h)。

**延伸**

如果树会频繁修改并频繁查询第 k 小，可以在每个节点上额外记录“子树节点数”，查询变成 O(h)。

给定一棵二叉树和其中的两个节点 `p`、`q`，找到它们的**最近公共祖先**：满足“既是 p 的祖先又是 q 的祖先”且深度最大的节点（一个节点也可以是自己的祖先）。

**示例**：`root = [3,5,1,6,2,0,8,null,null,7,4]`：`p = 5, q = 1` → `3`；`p = 5, q = 4` → `5`。
--- solution
package main

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
	// @solution
	if root == nil || root == p || root == q {
		return root
	}
	l := lowestCommonAncestor(root.Left, p, q)
	r := lowestCommonAncestor(root.Right, p, q)
	if l != nil && r != nil {
		return root // p、q 分别在两边，root 就是最近公共祖先
	}
	if l != nil {
		return l
	}
	return r
	// @starter
	// return nil
	// @end
}
--- test
package main

import (
	"fmt"
	"testing"

	if len(vals) == 0 || vals[0] == nil {
		return nil

	root := &TreeNode{Val: vals[0].(int)}

func find(n *TreeNode, v int) *TreeNode {
	if n == nil || n.Val == v {
		return n
	}
	if l := find(n.Left, v); l != nil {
		return l
	}
	return find(n.Right, v)
}

**思路**

后序递归，让函数返回“在这棵子树里找到的 p 或 q（或者它们的公共祖先）”：

- 当前节点是 nil、p 或 q，直接返回它；
- 否则分别在左右子树里找。**左右都找到了**，说明 p、q 分居两侧，当前节点就是最近公共祖先；只有一边找到，就把那一边的结果往上传。

**代码讲解**

1. `func lowestCommonAncestor(root, p, q *TreeNode)`：相同类型的参数可以合写。
2. `root == p`：比较的是**指针**，题目给的就是树中的节点。
3. 遇到 p（或 q）就直接返回，不再往下找：如果另一个节点在它下面，那么它自己就是答案；如果不在，另一边会找到另一个节点。
4. `l != nil && r != nil` 时返回 root；否则返回非 nil 的那一个（都是 nil 时返回 nil）。

**易错点**

- 用值比较 `root.Val == p.Val` 在值不唯一的树里会出错，比较指针最可靠。
- 这个写法依赖“p、q 一定在树里”的前提。

**复杂度**

时间 O(n)，空间 O(h)。

**延伸**

如果是二叉搜索树（235 题），可以利用大小关系：p、q 都比 root 小就去左边，都大就去右边，否则 root 就是答案。

package main

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

func rightSideView(root *TreeNode) []int {
	// @solution
	var res []int
	var dfs func(n *TreeNode, depth int)
	dfs = func(n *TreeNode, depth int) {
		if n == nil {
			return
		}
		if depth == len(res) {
			res = append(res, n.Val) // 先右后左，每层第一个到达的就是最右边的节点
		}
		dfs(n.Right, depth+1)
		dfs(n.Left, depth+1)
	}
	dfs(root, 0)
	return res
	// @starter
	// return nil
	// @end
}

--- solution
package main

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

func hasPathSum(root *TreeNode, targetSum int) bool {
	// @solution
	if root == nil {
		return false
	}
	if root.Left == nil && root.Right == nil { // 叶子节点
		return root.Val == targetSum
	}
	rest := targetSum - root.Val
	return hasPathSum(root.Left, rest) || hasPathSum(root.Right, rest)
	// @starter
	// return false
	// @end
}

**思路**

从根往下走，每经过一个节点就从目标值里减去它的值；走到**叶子节点**时，看剩下的值是否正好等于叶子的值。左右子树任意一边找到就返回 true。

**代码讲解**

2. `root.Left == nil && root.Right == nil`：叶子节点，直接判断。
3. `rest := targetSum - root.Val`：把问题缩小成“子树里是否有和为 rest 的路径”。

- `[1, 2], targetSum = 1`：根节点 1 不是叶子（它有左孩子），所以答案是 false。如果在 `root == nil` 时判断 `targetSum == 0`，会把“走到空的右孩子”误当成一条路径。**必须在叶子节点判断**。
