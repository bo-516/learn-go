slug: reverse-string
difficulty: 简单
category: 字符串

go: byte 与 rune, 多重赋值, 原地修改
--- desc
把以 `[]byte` 形式给出的字符串**原地**反转，只能使用 O(1) 的额外空间。

**示例**：`["h","e","l","l","o"]` → `["o","l","l","e","h"]`。
--- solution
package main

func reverseString(s []byte) {
	// @solution
	for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
		s[i], s[j] = s[j], s[i]
	}
	// @starter
	// @end
}
--- test
package main

import "testing"

func TestReverseString(t *testing.T) {
	cases := map[string]string{"hello": "olleh", "Hannah": "hannaH", "a": "a", "": "", "ab": "ba"}
	for in, want := range cases {
		b := []byte(in)
		reverseString(b)
		if string(b) != want {
			t.Errorf("reverseString(%q) → %q，期望 %q", in, b, want)
		}
	}
}
--- explain
`for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1` 在 for 语句里同时初始化和更新两个变量，是 Go 双指针的惯用写法。

注意这里是按**字节**反转。Go 的 string 是 UTF-8 编码的字节序列，如果要反转包含中文的字符串，必须先转成 `[]rune`，否则一个汉字的 3 个字节会被拆开反转，得到乱码。

把字符串中的大写字母转换为小写，并去掉所有**非字母数字**的字符之后，如果正着读和反着读一样，就是回文串。判断给定字符串是否是回文串。

**示例**：`"A man, a plan, a canal: Panama"` → `true`；`"race a car"` → `false`；`" "` → `true`。
--- solution
package main

import "unicode"

func isPalindrome(s string) bool {
	// @solution
	r := []rune(s)
	i, j := 0, len(r)-1
	for i < j {
		if !isAlnum(r[i]) {
			i++
			continue
		}
		if !isAlnum(r[j]) {
			j--
			continue
		}
		if unicode.ToLower(r[i]) != unicode.ToLower(r[j]) {
			return false
		}
		i++
		j--
	}
	return true
	// @starter
	// return false
	// @end
}

// @solution
func isAlnum(c rune) bool { return unicode.IsLetter(c) || unicode.IsDigit(c) }

// @end

--- solution
package main

func isAnagram(s string, t string) bool {
	// @solution
	var a, b [26]int
	for i := 0; i < len(s); i++ {
		a[s[i]-'a']++
	}
	for i := 0; i < len(t); i++ {
		b[t[i]-'a']++
	}
	return a == b
	// @starter
	// return false
	// @end
}
--- test

func TestIsAnagram(t *testing.T) {
	cases := []struct {
		s, t string
		want bool
	}{
		{"anagram", "nagaram", true},
		{"rat", "car", false},
		{"a", "ab", false},
		{"", "", true},
		{"aacc", "ccac", false},
	}

		if got := isAnagram(c.s, c.t); got != c.want {
			t.Errorf("isAnagram(%q, %q) = %v，期望 %v", c.s, c.t, got, c.want)
		}

--- desc
找出字符串数组中所有字符串的**最长公共前缀**，没有公共前缀返回空字符串。

**示例**：`["flower","flow","flight"]` → `"fl"`；`["dog","racecar","car"]` → `""`。
--- solution
package main

import "strings"

func longestCommonPrefix(strs []string) string {
	// @solution
	if len(strs) == 0 {
		return ""
	}
	prefix := strs[0]
	for _, s := range strs[1:] {
		for !strings.HasPrefix(s, prefix) {
			prefix = prefix[:len(prefix)-1]
		}
	}
	return prefix
	// @starter
	// return ""
	// @end
}
--- test
package main

import "testing"

func TestLongestCommonPrefix(t *testing.T) {
	cases := []struct {
		strs []string
		want string
	}{
		{[]string{"flower", "flow", "flight"}, "fl"},
		{[]string{"dog", "racecar", "car"}, ""},
		{[]string{"alone"}, "alone"},
		{[]string{"", "b"}, ""},
		{[]string{"ab", "abc", "abcd"}, "ab"},
		{[]string{"same", "same"}, "same"},
	}
	for _, c := range cases {
		if got := longestCommonPrefix(c.strs); got != c.want {
			t.Errorf("longestCommonPrefix(%q) = %q，期望 %q", c.strs, got, c.want)
		}
	}
}
--- explain
以第一个字符串作为候选前缀，不断截短直到它是每个字符串的前缀。`prefix[:len(prefix)-1]` 对字符串切片**不会拷贝**，新字符串和原字符串共享底层字节——Go 的 string 不可变，所以这样共享是安全的。

当 `prefix` 变成空字符串时，`strings.HasPrefix(s, "")` 永远为 true，循环自然结束。

slug: valid-parentheses
difficulty: 简单
category: 字符串
topics: 栈, 字符串
go: 切片当栈, map, byte 与 rune
--- desc
字符串只包含 `()[]{}`，判断括号是否有效：左括号必须用相同类型的右括号闭合，并且按正确的顺序闭合。

**示例**：`"()[]{}"` → `true`；`"(]"` → `false`；`"([)]"` → `false`；`"{[]}"` → `true`。
--- solution
package main

func isValid(s string) bool {
	// @solution
	pairs := map[rune]rune{')': '(', ']': '[', '}': '{'}
	var stack []rune
	for _, c := range s {
		if open, ok := pairs[c]; ok {
			if len(stack) == 0 || stack[len(stack)-1] != open {
				return false
			}
			stack = stack[:len(stack)-1]
		} else {
			stack = append(stack, c)
		}
	}
	return len(stack) == 0
	// @starter
	// return false
	// @end
}
--- test
package main

import "testing"

func TestIsValid(t *testing.T) {
	cases := map[string]bool{
		"()": true, "()[]{}": true, "(]": false, "([)]": false, "{[]}": true,
		"(": false, ")": false, "": true, "((()))[{}]": true, "){": false,
	}
	for in, want := range cases {
		if got := isValid(in); got != want {
			t.Errorf("isValid(%q) = %v，期望 %v", in, got, want)
		}
	}
}
--- explain
Go 没有内置的栈类型，用切片模拟：`append` 入栈，`s[len(s)-1]` 看栈顶，`s = s[:len(s)-1]` 出栈。

`for _, c := range s` 遍历字符串时，`c` 是 **rune**（按 UTF-8 解码后的字符），而 `s[i]` 取到的是 byte。所以 map 的类型是 `map[rune]rune`，字符字面量 `'('` 的默认类型也是 rune。

title: 同构字符串
slug: isomorphic-strings
difficulty: 简单
category: 字符串
topics: 字符串, 哈希表
go: map
--- desc
如果 `s` 中的字符可以按某种映射替换得到 `t`，那么两个字符串是同构的。映射必须一一对应：同一个字符只能映射到同一个字符，不同的字符不能映射到同一个字符（字符可以映射到自己）。

**示例**：`"egg", "add"` → `true`；`"foo", "bar"` → `false`；`"badc", "baba"` → `false`。
--- solution
package main

func isIsomorphic(s string, t string) bool {
	// @solution
	if len(s) != len(t) {
		return false
	}
	st := map[byte]byte{}
	ts := map[byte]byte{}
	for i := 0; i < len(s); i++ {
		a, b := s[i], t[i]
		if x, ok := st[a]; ok && x != b {
			return false
		}
		if y, ok := ts[b]; ok && y != a {
			return false
		}
		st[a], ts[b] = b, a
	}
	return true
	// @starter
	// return false
	// @end
}
--- test
package main

import "testing"

func TestIsIsomorphic(t *testing.T) {
	cases := []struct {
		s, t string
		want bool
	}{
		{"egg", "add", true},
		{"foo", "bar", false},
		{"paper", "title", true},
		{"badc", "baba", false},
		{"a", "a", true},
		{"ab", "aa", false},
	}
	for _, c := range cases {
		if got := isIsomorphic(c.s, c.t); got != c.want {
			t.Errorf("isIsomorphic(%q, %q) = %v，期望 %v", c.s, c.t, got, c.want)
		}
	}
}
--- explain
「一一对应」需要**两个方向**都检查：只检查 s→t，`"badc" / "baba"` 会误判为同构（b→b、a→a、d→b、c→a，但 b 和 d 映射到了同一个字符）。

`if x, ok := st[a]; ok && x != b` 是 if 带初始化语句的写法，`x` 和 `ok` 的作用域只在这个 if 里。

--- solution
package main

import "strings"

func wordPattern(pattern string, s string) bool {
	// @solution
	words := strings.Fields(s)
	if len(words) != len(pattern) {
		return false
	}
	p2w := map[byte]string{}
	w2p := map[string]byte{}
	for i, w := range words {
		p := pattern[i]
		if x, ok := p2w[p]; ok && x != w {
			return false
		}
		if y, ok := w2p[w]; ok && y != p {
			return false
		}
		p2w[p], w2p[w] = w, p
	}
	return true
	// @starter
	// return false
	// @end
}

package main

func value(c byte) int {
	// @solution
	switch c {
	case 'I':
		return 1
	case 'V':
		return 5
	case 'X':
		return 10
	case 'L':
		return 50
	case 'C':
		return 100
	case 'D':
		return 500
	case 'M':
		return 1000
	}
	return 0
	// @starter
	// return 0
	// @end
}

func romanToInt(s string) int {
	// @solution
	total := 0
	for i := 0; i < len(s); i++ {
		v := value(s[i])
		if i+1 < len(s) && v < value(s[i+1]) {
			total -= v
		} else {
			total += v
		}
	}
	return total
	// @starter
	// return 0
	// @end
}

package main

import "strconv"

func fizzBuzz(n int) []string {
	// @solution
	out := make([]string, 0, n)
	for i := 1; i <= n; i++ {
		switch {
		case i%15 == 0:
			out = append(out, "FizzBuzz")
		case i%3 == 0:
			out = append(out, "Fizz")
		case i%5 == 0:
			out = append(out, "Buzz")
		default:
			out = append(out, strconv.Itoa(i))
		}
	}
	return out
	// @starter
	// return nil
	// @end
}

		t.Fatalf("fizzBuzz(15) = %v", got)
	}
	if got := fizzBuzz(1); !slices.Equal(got, []string{"1"}) {
		t.Fatalf("fizzBuzz(1) = %v", got)
	}
}
--- explain
整数转字符串用 `strconv.Itoa(i)`，**不要**写 `string(i)`——后者把整数当作 Unicode 码点，`string(65)` 得到的是 `"A"`（`go vet` 会对此报警）。

`switch` 的 case 按顺序匹配，所以 15 的倍数要放在最前面。

--- desc
给定两个二进制字符串 `a` 和 `b`，以二进制字符串的形式返回它们的和。输入可能很长（超过 64 位），不能直接转成整数相加。

**示例**：`a = "11", b = "1"` → `"100"`；`a = "1010", b = "1011"` → `"10101"`。
--- solution
package main

func addBinary(a string, b string) string {
	// @solution
	out := make([]byte, 0, max(len(a), len(b))+1)
	i, j, carry := len(a)-1, len(b)-1, 0
	for i >= 0 || j >= 0 || carry > 0 {
		sum := carry
		if i >= 0 {
			sum += int(a[i] - '0')
			i--
		}
		if j >= 0 {
			sum += int(b[j] - '0')
			j--
		}
		out = append(out, byte('0'+sum%2))
		carry = sum / 2
	}
	for l, r := 0, len(out)-1; l < r; l, r = l+1, r-1 {
		out[l], out[r] = out[r], out[l]
	}
	return string(out)
	// @starter
	// return ""
	// @end
}
--- test
package main

import (
	"strings"
	"testing"
)

func TestAddBinary(t *testing.T) {
	cases := []struct{ a, b, want string }{
		{"11", "1", "100"},
		{"1010", "1011", "10101"},
		{"0", "0", "0"},
		{"1", "111", "1000"},
		{strings.Repeat("1", 100), "1", "1" + strings.Repeat("0", 100)},
	}
	for _, c := range cases {
		if got := addBinary(c.a, c.b); got != c.want {
			t.Errorf("addBinary(%q, %q) = %q，期望 %q", c.a, c.b, got, c.want)
		}
	}
}
--- explain
从低位开始逐位相加，`a[i] - '0'` 把字符 `'0'`/`'1'` 转换成数字 0/1，`byte('0' + sum%2)` 再转回字符。

结果先按低位到高位追加到 `[]byte`，最后反转一次，比每次在字符串前面拼接（每次都要分配新字符串）高效得多。
