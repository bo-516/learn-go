title: 每日温度
slug: daily-temperatures
difficulty: 中等
category: 栈与单调栈
topics: 栈, 数组, 单调栈
go: 切片当栈, 切片
--- desc
给定每天的温度数组 `temperatures`，返回数组 `answer`：`answer[i]` 表示第 i 天之后还要等几天才会出现**更高**的温度；如果之后都不会更高，填 0。

**示例**：`[73,74,75,71,69,72,76,73]` → `[1,1,4,2,1,1,0,0]`。
--- solution
package main

func dailyTemperatures(temperatures []int) []int {
	// @solution
	ans := make([]int, len(temperatures))
	var stack []int // 存下标，对应的温度从栈底到栈顶递减（还没等到更高温度的日子）
	for i, t := range temperatures {
		for len(stack) > 0 && temperatures[stack[len(stack)-1]] < t {
			j := stack[len(stack)-1]
			stack = stack[:len(stack)-1]
			ans[j] = i - j // 第 j 天终于等到了更高的温度
		}
		stack = append(stack, i)
	}
	return ans
	// @starter
	// return nil
	// @end
}
--- test
package main

import (
	"slices"
	"testing"
)

func TestDailyTemperatures(t *testing.T) {
	cases := []struct{ in, want []int }{
		{[]int{73, 74, 75, 71, 69, 72, 76, 73}, []int{1, 1, 4, 2, 1, 1, 0, 0}},
		{[]int{30, 40, 50, 60}, []int{1, 1, 1, 0}},
		{[]int{30, 60, 90}, []int{1, 1, 0}},
		{[]int{90, 80, 70}, []int{0, 0, 0}},
		{[]int{50}, []int{0}},
		{[]int{70, 70, 71}, []int{2, 1, 0}},
	}
	for _, c := range cases {
		if got := dailyTemperatures(c.in); !slices.Equal(got, c.want) {
			t.Errorf("dailyTemperatures(%v) = %v，期望 %v", c.in, got, c.want)
		}
	}
}
--- explain
**思路**

**单调栈**：栈里存“还没找到更高温度”的日子的下标，它们的温度从栈底到栈顶递减。遍历到新的一天时，只要它比栈顶那天更热，栈顶那天的答案就确定了（就是今天），弹出并记录，继续比较新的栈顶。最后把今天压栈。

**代码讲解**

1. `ans := make([]int, len(temperatures))`：默认值 0 正好表示“之后没有更高温度”，栈里剩下的日子不用再处理。
2. `var stack []int`：存**下标**而不是温度，因为既要比较温度（`temperatures[j]`），又要计算天数差（`i - j`）。
3. `for len(stack) > 0 && temperatures[stack[len(stack)-1]] < t`：**for 而不是 if**，今天可能同时是好几天的答案。
4. 弹栈、记录 `ans[j] = i - j`。
5. `stack = append(stack, i)`：今天入栈，等待之后更热的日子。

**易错点**

- 比较用 `<` 而不是 `<=`：温度相同不算“更高”，相等的日子都要留在栈里。
- 暴力做法对每天往后找，最坏 O(n²)。

**复杂度**

时间 O(n)：每个下标最多入栈、出栈各一次。空间 O(n)。

**延伸**

单调栈专门解决“找下一个更大 / 更小的元素”这一类问题，例如「下一个更大元素」「柱状图中最大的矩形」「接雨水」。

slug: decode-string
difficulty: 中等

--- desc
编码规则是 `k[encoded_string]`，表示方括号内的字符串重复 k 次（k 是正整数，可能有多位），可以嵌套。给定合法的编码字符串 `s`，返回解码后的字符串。

**示例**：`"3[a]2[bc]"` → `"aaabcbc"`；`"3[a2[c]]"` → `"accaccacc"`；`"2[abc]3[cd]ef"` → `"abcabccdcdcdef"`。
--- solution
package main

import "strings"

func decodeString(s string) string {
	// @solution
	var counts []int   // 每层 '[' 前面的重复次数
	var prefix []string // 每层 '[' 之前已经拼好的字符串
	cur, num := "", 0
	for i := 0; i < len(s); i++ {
		c := s[i]
		switch {
		case c >= '0' && c <= '9':
			num = num*10 + int(c-'0') // 数字可能有多位
		case c == '[':
			counts = append(counts, num)
			prefix = append(prefix, cur)
			cur, num = "", 0
		case c == ']':
			k := counts[len(counts)-1]
			counts = counts[:len(counts)-1]
			p := prefix[len(prefix)-1]
			prefix = prefix[:len(prefix)-1]
			cur = p + strings.Repeat(cur, k)
		default:
			cur += string(c)
		}
	}
	return cur
	// @starter
	// return ""
	// @end
}
--- test
package main

import "testing"

func TestDecodeString(t *testing.T) {
	cases := []struct{ in, want string }{
		{"3[a]2[bc]", "aaabcbc"},
		{"3[a2[c]]", "accaccacc"},
		{"2[abc]3[cd]ef", "abcabccdcdcdef"},
		{"abc3[cd]xyz", "abccdcdcdxyz"},
		{"10[a]", "aaaaaaaaaa"},
		{"leetcode", "leetcode"},
		{"2[a2[b2[c]]]", "abccbccabccbcc"},
	}
	for _, c := range cases {
		if got := decodeString(c.in); got != c.want {
			t.Errorf("decodeString(%q) = %q，期望 %q", c.in, got, c.want)
		}
	}
}
--- explain
**思路**

括号可以嵌套，遇到 `[` 就要“进入新的一层”，遇到 `]` 就“回到上一层”，用栈保存外层的状态：**外层已经拼好的字符串**和**这一层要重复的次数**。

**代码讲解**

1. 两个栈 `counts`、`prefix`，用切片模拟。也可以定义一个结构体 `struct{ k int; p string }` 只用一个栈。
2. `cur` 是当前层正在拼的字符串，`num` 是正在读的数字。
3. 数字：`num = num*10 + int(c-'0')`，处理 `10[a]` 这种多位数。
4. `[`：把 `num` 和 `cur` 压栈，然后清空，开始新的一层。`cur, num = "", 0` 一行重置两个变量。
5. `]`：弹出次数 k 和外层前缀 p，`cur = p + strings.Repeat(cur, k)`：当前层重复 k 次后接回外层。
6. 字母：追加到 `cur`。

**易错点**

- 只处理一位数字，`10[a]` 会变成 `1` 和 `0[a]`。
- 字符串 `+=` 在循环中拼接会反复分配，这里输入很短无所谓；更长的输入可以把 `cur` 换成 `[]byte`。
- 不能用 `strings.Builder` 放进栈（切片）里：Builder 写入后被复制再使用会 panic。

**复杂度**

时间 O(输出长度)，空间 O(输出长度)。

**延伸**

也可以用递归：遇到 `[` 递归解析内层，返回内层字符串和结束位置，代码同样清晰。

category: 栈与单调栈

--- desc
给定逆波兰表示法（后缀表达式）的字符串数组 `tokens`，计算表达式的值。运算符只有 `+`、`-`、`*`、`/`，除法**向零截断**。保证表达式合法且不会除以 0。

**示例**：`["2","1","+","3","*"]` → `9`（`(2 + 1) * 3`）；`["4","13","5","/","+"]` → `6`（`4 + 13 / 5`）。
--- solution
package main

import "strconv"

func evalRPN(tokens []string) int {
	// @solution
	var st []int
	for _, tok := range tokens {
		switch tok {
		case "+", "-", "*", "/":
			a, b := st[len(st)-2], st[len(st)-1] // 注意顺序：先入栈的是左操作数
			st = st[:len(st)-2]
			var r int
			switch tok {
			case "+":
				r = a + b
			case "-":
				r = a - b
			case "*":
				r = a * b
			case "/":
				r = a / b // Go 的整数除法本来就是向零截断
			}
			st = append(st, r)
		default:
			n, _ := strconv.Atoi(tok) // 题目保证是合法数字
			st = append(st, n)
		}
	}
	return st[0]
	// @starter
	// return 0
	// @end
}
--- test
package main

import "testing"

func TestEvalRPN(t *testing.T) {
	cases := []struct {
		tokens []string
		want   int
	}{
		{[]string{"2", "1", "+", "3", "*"}, 9},
		{[]string{"4", "13", "5", "/", "+"}, 6},
		{[]string{"10", "6", "9", "3", "+", "-11", "*", "/", "*", "17", "+", "5", "+"}, 22},
		{[]string{"18"}, 18},
		{[]string{"3", "-4", "/"}, 0},
		{[]string{"-7", "2", "/"}, -3},
		{[]string{"5", "8", "-"}, -3},
	}
	for _, c := range cases {
		if got := evalRPN(c.tokens); got != c.want {
			t.Errorf("evalRPN(%q) = %d，期望 %d", c.tokens, got, c.want)
		}
	}
}
--- explain
**思路**

后缀表达式天然适合用栈求值：遇到数字入栈；遇到运算符就弹出两个数计算，把结果压回栈。最后栈里剩下的唯一一个数就是结果。

**代码讲解**

1. `switch tok { case "+", "-", "*", "/": ...}`：一个 case 列出多个值。
2. `a, b := st[len(st)-2], st[len(st)-1]`：**先入栈的是左操作数**。`"5" "8" "-"` 是 `5 - 8`，不是 `8 - 5`。
3. `st = st[:len(st)-2]`：一次弹出两个。
4. 内层 `switch` 计算，`var r int` 先声明再在分支里赋值。
5. `a / b`：Go 的整数除法**向零截断**（`-7 / 2 == -3`），正好符合题意，不需要像 Python 那样特殊处理。
6. `default` 分支：`strconv.Atoi` 把字符串转成整数，能正确处理 `"-11"` 这种负数。题目保证合法，所以忽略了错误。

**易错点**

- 减法和除法的操作数顺序写反。
- 把 `"-11"` 当成运算符：判断运算符要用完整的字符串比较，而不是看第一个字符。

**复杂度**

时间 O(n)，空间 O(n)。

`nums1` 是 `nums2` 的子集，两个数组都没有重复元素。对 `nums1` 中的每个数 x，找出 x 在 `nums2` 中的位置右边**第一个比 x 大**的数；不存在则为 -1。

**示例**：`nums1 = [4,1,2], nums2 = [1,3,4,2]` → `[-1,3,-1]`。
--- solution
package main

func nextGreaterElement(nums1 []int, nums2 []int) []int {
	// @solution
	next := make(map[int]int, len(nums2)) // 值 → 右边第一个更大的数
	var stack []int                       // 单调递减栈，存还没找到答案的数
	for _, v := range nums2 {
		for len(stack) > 0 && stack[len(stack)-1] < v {
			next[stack[len(stack)-1]] = v
			stack = stack[:len(stack)-1]
		}
		stack = append(stack, v)
	}
	ans := make([]int, len(nums1))
	for i, v := range nums1 {
		if g, ok := next[v]; ok {
			ans[i] = g
		} else {
			ans[i] = -1
		}
	}
	return ans
	// @starter
	// return nil
	// @end
}
--- test
package main

import (
	"slices"
	"testing"

	cases := []struct{ a, b, want []int }{
		{[]int{4, 1, 2}, []int{1, 3, 4, 2}, []int{-1, 3, -1}},
		{[]int{2, 4}, []int{1, 2, 3, 4}, []int{3, -1}},
		{[]int{1}, []int{1}, []int{-1}},
		{[]int{1, 3, 5, 2, 4}, []int{6, 5, 4, 3, 2, 1, 7}, []int{7, 7, 7, 7, 7}},
	}
	for _, c := range cases {
		if got := nextGreaterElement(c.a, c.b); !slices.Equal(got, c.want) {

--- explain
**思路**

分两步：先用**单调栈**一次遍历 `nums2`，求出每个数“右边第一个更大的数”存进 map；再对 `nums1` 的每个数查表。

**代码讲解**

1. `next := make(map[int]int, len(nums2))`：没有重复元素，所以可以用值做 key。
2. 遍历 `nums2`：栈顶比当前数小，说明当前数就是栈顶“右边第一个更大的数”，记录并弹出；循环直到栈顶不再比当前数小，再把当前数入栈。栈里的数从底到顶递减。
3. 遍历结束后还留在栈里的数，右边没有更大的，不在 map 里。
4. 查表时用 comma-ok：找不到就是 -1。

**易错点**

- 暴力做法对 `nums1` 每个数在 `nums2` 里先找位置、再往右找，O(m·n)。
- 这里栈里存的是值（因为只需要值）；「每日温度」需要算距离，所以存下标。

**复杂度**

时间 O(m + n)，空间 O(n)。

slug: search-insert-position
difficulty: 简单
category: 二分查找
topics: 数组, 二分查找
go: 整数运算, for 当 while
--- desc
给定**升序**、无重复元素的数组 `nums` 和目标值 `target`：如果找到目标值就返回下标，否则返回它应该被按顺序插入的位置。要求 O(log n)。

**示例**：`nums = [1,3,5,6]`：`target = 5` → `2`；`target = 2` → `1`；`target = 7` → `4`。
--- solution
package main

func searchInsert(nums []int, target int) int {
	// @solution
	lo, hi := 0, len(nums) // 左闭右开区间 [lo, hi)
	for lo < hi {
		mid := lo + (hi-lo)/2
		if nums[mid] < target {
			lo = mid + 1 // 答案在 mid 右边
		} else {
			hi = mid // nums[mid] >= target，mid 可能就是答案
		}
	}
	return lo // 第一个 >= target 的位置
	// @starter
	// return -1
	// @end
}
--- test
package main

import "testing"

func TestSearchInsert(t *testing.T) {
	cases := []struct {
		nums   []int
		target int
		want   int
	}{
		{[]int{1, 3, 5, 6}, 5, 2},
		{[]int{1, 3, 5, 6}, 2, 1},
		{[]int{1, 3, 5, 6}, 7, 4},
		{[]int{1, 3, 5, 6}, 0, 0},
		{[]int{1}, 1, 0},
		{[]int{1, 3}, 3, 1},
		{[]int{}, 5, 0},
	}
	for _, c := range cases {
		if got := searchInsert(c.nums, c.target); got != c.want {
			t.Errorf("searchInsert(%v, %d) = %d，期望 %d", c.nums, c.target, got, c.want)
		}
	}
}
--- explain
**思路**

“插入位置”就是**第一个大于等于 target 的位置**（lower bound）。找到 target 时它就是 target 的下标，找不到时就是插入位置，两种情况一个二分就搞定。

**代码讲解**

1. `lo, hi := 0, len(nums)`：**左闭右开**区间 `[lo, hi)`。`hi` 取 `len(nums)` 是因为答案可能是“插在最后”。
2. `for lo < hi`：区间非空时继续。
3. `nums[mid] < target`：mid 太小，答案在 `[mid+1, hi)`。
4. 否则 `hi = mid`：mid 满足条件，**可能就是答案**，所以不能写 `mid - 1`。
5. 循环结束时 `lo == hi`，就是第一个 ≥ target 的位置。

**易错点**

- 左闭右开写法里写成 `hi = mid - 1` 会漏掉答案；闭区间写法里写成 `hi = mid` 会死循环。**区间定义和边界更新要配套**。
- 空数组返回 0。

**复杂度**

时间 O(log n)，空间 O(1)。

**延伸**

标准库：`i, found := slices.BinarySearch(nums, target)` 返回的 `i` 正是这个插入位置；`sort.SearchInts(nums, target)` 也是。

title: 在排序数组中查找元素的第一个和最后一个位置
slug: find-first-and-last-position-of-element-in-sorted-array
difficulty: 中等
category: 二分查找
topics: 数组, 二分查找
go: 闭包, 切片
--- desc
给定**非递减**数组 `nums` 和目标值 `target`，找出 target 在数组中的开始位置和结束位置；不存在返回 `[-1, -1]`。要求 O(log n)。

**示例**：`nums = [5,7,7,8,8,10], target = 8` → `[3,4]`；`target = 6` → `[-1,-1]`。
--- solution
package main

func searchRange(nums []int, target int) []int {
	// @solution
	// lower 返回第一个 >= x 的下标
	lower := func(x int) int {
		lo, hi := 0, len(nums)
		for lo < hi {
			mid := lo + (hi-lo)/2
			if nums[mid] < x {
				lo = mid + 1
			} else {
				hi = mid
			}
		}
		return lo
	}
	l := lower(target)
	if l == len(nums) || nums[l] != target {
		return []int{-1, -1}
	}
	return []int{l, lower(target+1) - 1} // 第一个 > target 的位置减 1
	// @starter
	// return []int{-1, -1}
	// @end
}
--- test
package main

import (
	"slices"
	"testing"
)

func TestSearchRange(t *testing.T) {
	cases := []struct {
		nums   []int
		target int
		want   []int
	}{
		{[]int{5, 7, 7, 8, 8, 10}, 8, []int{3, 4}},
		{[]int{5, 7, 7, 8, 8, 10}, 6, []int{-1, -1}},
		{[]int{}, 0, []int{-1, -1}},
		{[]int{1}, 1, []int{0, 0}},
		{[]int{2, 2}, 2, []int{0, 1}},
		{[]int{1, 2, 3}, 3, []int{2, 2}},
		{[]int{1, 1, 1, 1}, 1, []int{0, 3}},
	}
	for _, c := range cases {
		if got := searchRange(c.nums, c.target); !slices.Equal(got, c.want) {
			t.Errorf("searchRange(%v, %d) = %v，期望 %v", c.nums, c.target, got, c.want)
		}
	}
}
--- explain
**思路**

两个边界都可以用同一个“找第一个 ≥ x 的位置”的二分求出来：

- 开始位置 = 第一个 ≥ target 的位置；
- 结束位置 = 第一个 ≥ target+1（也就是 > target）的位置 − 1。

**代码讲解**

1. `lower := func(x int) int {...}`：在函数内定义一个**闭包**，它直接使用外层的 `nums`，不用把切片当参数传来传去。
2. 闭包内部是标准的左闭右开二分（和「搜索插入位置」完全一样）。
3. `if l == len(nums) || nums[l] != target`：`l == len(nums)` 说明所有数都比 target 小；`||` 短路保证不会越界访问 `nums[l]`。
4. 结束位置 `lower(target+1) - 1`：因为数组元素是整数，“> target”等价于“≥ target+1”。

**易错点**

- 找到 target 后向左右线性扩展，在 `[8,8,8,...,8]` 这种数组上会退化成 O(n)。
- `target + 1` 的技巧只适用于整数；浮点数或一般情况要单独写一个“第一个 > x”的二分（`nums[mid] <= x` 时 `lo = mid + 1`）。

**复杂度**

时间 O(log n)，空间 O(1)。

--- desc
升序、元素互不相同的数组在某个下标处被“旋转”过（例如 `[0,1,2,4,5,6,7]` 变成 `[4,5,6,7,0,1,2]`）。给定旋转后的数组 `nums` 和 `target`，返回 target 的下标，不存在返回 -1。要求 O(log n)。

**示例**：`nums = [4,5,6,7,0,1,2]`：`target = 0` → `4`；`target = 3` → `-1`。
--- solution
package main

func search(nums []int, target int) int {
	// @solution
	lo, hi := 0, len(nums)-1
	for lo <= hi {
		mid := lo + (hi-lo)/2
		if nums[mid] == target {
			return mid
		}
		if nums[lo] <= nums[mid] { // 左半段 [lo, mid] 是有序的
			if nums[lo] <= target && target < nums[mid] {
				hi = mid - 1
			} else {
				lo = mid + 1
			}
		} else { // 右半段 [mid, hi] 是有序的
			if nums[mid] < target && target <= nums[hi] {
				lo = mid + 1
			} else {
				hi = mid - 1
			}
		}
	}
	return -1
	// @starter
	// return -1
	// @end
}
--- test
package main

import "testing"

func TestSearch(t *testing.T) {
	cases := []struct {
		nums   []int
		target int
		want   int
	}{
		{[]int{4, 5, 6, 7, 0, 1, 2}, 0, 4},
		{[]int{4, 5, 6, 7, 0, 1, 2}, 3, -1},
		{[]int{1}, 0, -1},
		{[]int{1}, 1, 0},
		{[]int{3, 1}, 1, 1},
		{[]int{5, 1, 3}, 5, 0},
		{[]int{6, 7, 1, 2, 3, 4, 5}, 6, 0},
		{[]int{1, 2, 3, 4, 5}, 4, 3},
	}
	for _, c := range cases {
		if got := search(c.nums, c.target); got != c.want {
			t.Errorf("search(%v, %d) = %d，期望 %d", c.nums, c.target, got, c.want)
		}
	}
}
--- explain
**思路**

旋转数组从任意位置 mid 切开，**两半中至少有一半是有序的**。判断哪一半有序，再看 target 是否落在这个有序区间里：在就去这一半找，不在就去另一半找。

**代码讲解**

1. 闭区间二分：`lo, hi := 0, len(nums)-1`、`for lo <= hi`。
2. 先判断 `nums[mid] == target`。
3. `nums[lo] <= nums[mid]`：左半段有序。用 `<=` 是因为 `lo == mid` 时左半段只有一个元素，也算有序。
4. target 在 `[nums[lo], nums[mid])` 范围内就去左边，否则去右边。
5. 否则右半段有序，target 在 `(nums[mid], nums[hi]]` 范围内就去右边，否则去左边。

**易错点**

- 第 3 步写成 `<` 会在 `[3, 1]` 找 1 时出错。
- 判断范围时边界的开闭要仔细：mid 已经比较过了，所以 mid 那一端是开的。

**复杂度**

时间 O(log n)，空间 O(1)。

--- desc
升序、元素互不相同的数组旋转了若干次（例如 `[0,1,2,4,5,6,7]` 可能变成 `[4,5,6,7,0,1,2]`）。找出数组中的最小元素，要求 O(log n)。

**示例**：`[3,4,5,1,2]` → `1`；`[4,5,6,7,0,1,2]` → `0`；`[11,13,15,17]` → `11`。
--- solution
package main

func findMin(nums []int) int {
	// @solution
	lo, hi := 0, len(nums)-1
	for lo < hi {
		mid := lo + (hi-lo)/2
		if nums[mid] > nums[hi] {
			lo = mid + 1 // mid 在左边那段较大的部分，最小值在 mid 右边
		} else {
			hi = mid // mid 在右边那段较小的部分，最小值是 mid 或在它左边
		}
	}
	return nums[lo]
	// @starter
	// return 0
	// @end
}
--- test
package main

import "testing"

func TestFindMin(t *testing.T) {
	cases := []struct {
		nums []int
		want int
	}{
		{[]int{3, 4, 5, 1, 2}, 1},
		{[]int{4, 5, 6, 7, 0, 1, 2}, 0},
		{[]int{11, 13, 15, 17}, 11},
		{[]int{2, 1}, 1},
		{[]int{1}, 1},
		{[]int{5, 6, 7, 8, 9, 1, 2, 3, 4}, 1},
	}
	for _, c := range cases {
		if got := findMin(c.nums); got != c.want {
			t.Errorf("findMin(%v) = %d，期望 %d", c.nums, got, c.want)
		}
	}
}
--- explain
**思路**

旋转后的数组是两段升序：左段的每个数都比右段大，最小值是右段的第一个数。拿 `nums[mid]` 和**区间最右边的数** `nums[hi]` 比较就能知道 mid 在哪一段：

- `nums[mid] > nums[hi]`：mid 在左段，最小值在 mid 右边；
- 否则 mid 在右段，最小值是 mid 或在它左边。

**代码讲解**

1. `for lo < hi`：区间缩到一个元素时就是答案。
2. `lo = mid + 1`：mid 本身比 `nums[hi]` 大，不可能是最小值，可以排除。
3. `hi = mid`：mid 可能就是最小值，不能排除，所以不是 `mid - 1`。
4. 返回 `nums[lo]`。

**易错点**

- 和 `nums[lo]` 比较不行：没有旋转的数组 `[1, 2, 3]` 里 `nums[mid] > nums[lo]`，最小值却在左边。和右端比较不会有这个问题。
- 循环条件写成 `lo <= hi` 配 `hi = mid` 会死循环。

**复杂度**

时间 O(log n)，空间 O(1)。
