**思路**

交集要保留重复次数，所以不能用集合，要用**计数**：先统计一个数组里每个数出现几次，再遍历另一个数组，计数大于 0 就放进结果并减 1。

**代码讲解**

1. `if len(nums1) > len(nums2) { nums1, nums2 = nums2, nums1 }`：交换两个参数，保证用**较小的**数组建表，map 更小。参数本身就是局部变量，可以重新赋值。
2. `count[v]++`：map 中不存在的 key 读出来是零值 0，所以直接 `++`，不需要先判断。
3. `var out []int`：nil 切片，可以直接 append。
4. `if count[v] > 0`：同样利用零值，不存在的数计数是 0。
5. 放进结果后 `count[v]--`，保证每个数最多取 min(两边出现次数) 次。

**易错点**

- 没有交集时返回 nil；测试如果用 `reflect.DeepEqual` 比较 `[]int{}` 会不相等，所以测试里一般先判断长度。
- 如果两个数组已经有序，可以用双指针做到 O(1) 额外空间。

**复杂度**

时间 O(m + n)，空间 O(min(m, n))。

**思路**

先假设第一个字符串就是公共前缀，然后用后面的每个字符串去“削短”它：只要当前字符串不以 prefix 开头，就把 prefix 去掉最后一个字符。

**思路**

括号匹配是最典型的**栈**问题：遇到左括号入栈；遇到右括号时，栈顶必须是对应的左括号，否则不合法。最后栈必须为空。

**代码讲解**

1. `pairs := map[rune]rune{')': '(', ...}`：右括号 → 对应左括号。用 map 字面量初始化。
2. `var stack []rune`：Go 没有内置栈，用切片模拟：`append` 入栈，`stack[len(stack)-1]` 看栈顶，`stack[:len(stack)-1]` 出栈。
3. `for _, c := range s`：遍历字符串得到的 `c` 是 rune。
4. `if open, ok := pairs[c]; ok`：c 是右括号。先检查栈是否为空（`len(stack) == 0`），再比较栈顶；`||` 短路求值保证空栈时不会访问 `stack[-1]`。
5. 其他字符（左括号）入栈。
6. `return len(stack) == 0`：还有没匹配的左括号也不合法。

**易错点**

- 忘了最后检查栈为空，`"(("` 会被误判为合法。
- 出栈后不要忘了赋值回 `stack`。

**复杂度**

时间 O(n)，空间 O(n)。

**思路**

同构要求字符之间是**一一映射**：s 的同一个字符总是映射到 t 的同一个字符，并且 t 的同一个字符也只能被 s 的一个字符映射。所以要两个 map 双向检查。

**代码讲解**

1. 长度不同直接返回 false。
2. `st`、`ts` 两个 map：s→t 和 t→s。
3. `a, b := s[i], t[i]`：按字节同时取两个字符串的第 i 个字符。
4. `if x, ok := st[a]; ok && x != b`：a 已经有映射，但映射的不是 b，冲突。反方向同理。
5. `st[a], ts[b] = b, a`：多重赋值同时记录两个方向。

**易错点**

- 只检查一个方向会把 `s = "ab", t = "aa"` 误判为同构（a→a、b→a，两个字符映射到同一个）。
- 另一种写法：比较“每个字符第一次出现的位置”序列是否相同。

**复杂度**

时间 O(n)，空间 O(字符集大小)。

**思路**

罗马数字一般从大到小排列，直接相加；特殊情况是小的数字在大的左边（如 IV、IX），表示减法。所以规则是：**如果当前字符比右边的小，就减去它，否则加上它**。

**代码讲解**

3. `if i+1 < len(s) && v < value(s[i+1])`：先检查下标不越界再看右边的字符（短路求值）。

- switch 最后的 `return 0` 不能省：Go 要求函数所有路径都有返回值。

=== lc-67
--- explain
**思路**

模拟竖式加法：从两个字符串的末尾开始逐位相加，带上进位。结果是倒着生成的，最后反转。

**代码讲解**

1. `make([]byte, 0, max(len(a), len(b))+1)`：结果最多比较长的数多一位，预分配容量。
2. `i, j, carry := len(a)-1, len(b)-1, 0`：两个指针从末尾开始，进位初始为 0。
3. `for i >= 0 || j >= 0 || carry > 0`：只要还有位没加完或还有进位就继续，这样最后的进位不需要单独处理。
4. `int(a[i] - '0')`：字符 `'0'`/`'1'` 转成数字 0/1。
5. `byte('0' + sum%2)`：当前位，再转回字符；`carry = sum / 2`。
6. 最后双指针原地反转，`string(out)` 得到结果。

**易错点**

- 不能转成整数相加：字符串长度可达 10⁴，远超 int64。
- 循环条件漏掉 `carry > 0`，`"1" + "1"` 会得到 `"0"`。

**复杂度**

时间 O(max(m, n))，空间 O(max(m, n))。

=== lc-9
--- explain
**思路**

不转字符串：把数字的**后一半**反转，和前一半比较。每次从 x 末尾取一位加到 rev 上，直到 rev ≥ x，说明已经处理了一半。

**代码讲解**

1. 负数一定不是回文；末尾是 0 的数（除了 0 本身）也不是，因为开头不可能是 0。这两种情况提前返回。
2. `for x > rev`：for 当 while 用。
3. `rev = rev*10 + x%10`：取 x 的最后一位追加到 rev；`x /= 10` 去掉最后一位（整数除法）。
4. 结束时：位数为偶数，`x == rev`（如 1221 → x=12, rev=12）；位数为奇数，中间那位在 rev 的末尾，`x == rev/10`（如 12321 → x=12, rev=123）。

**易错点**

- 完全反转整个数字可能溢出（在其他语言里），反转一半就没有这个问题。
- 末尾为 0 的判断不能省：反转时末尾的 0 会变成 rev 的前导 0 而被丢掉，`x = 10` 最后得到 `x = 0, rev = 1`（满足 `x == rev/10`），`x = 110` 得到 `x = 1, rev = 1`，都会被误判为回文。

**复杂度**

时间 O(log x)（位数），空间 O(1)。
